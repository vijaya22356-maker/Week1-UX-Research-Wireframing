## Problem Statement

Many students find it difficult to maintain a consistent fitness routine due to busy academic schedules and lack of proper tracking tools. They often forget their workout plans, fail to monitor their daily progress, and lose motivation over time.

## User Interviews

User 1: Forgets workout schedule because of academic workload.

User 2: Unable to track fitness progress consistently.

User 3: Needs motivation and progress tracking to stay committed.

## User Flow

Open Application → Login → Dashboard → Set Fitness Goals → Add Daily Workout Activities → Track Progress → View Reports and Achievements
